# 💰 TaxPal – Personal Finance & Tax Estimator for Freelancers

TaxPal is a full-stack web application designed to help freelancers and gig workers efficiently manage their personal finances. The platform enables users to securely track income and expenses, categorize transactions, create monthly budgets, estimate quarterly taxes, and generate downloadable financial reports.

The project aims to simplify financial management by providing an intuitive dashboard, real-time expense tracking, tax estimation based on user location, and organized financial insights in one place.

## 🚀 Key Features

- 🔐 Secure User Authentication (Signup & Login)
- 💵 Income and Expense Management
- 📂 Transaction Categorization
- 📊 Budget Planning & Spending Analysis
- 🧾 Quarterly Tax Estimation
- 📅 Tax Reminder Support
- 📄 Financial Report Generation (PDF/CSV)
- 📱 Responsive User Interface

## 🛠️ Tech Stack

### Frontend
- Angular
  
### Backend
- Node.js
- Express.js
- JWT Authentication
- bcrypt

### Database
- MySQL

## 📌 Project Goal

The primary goal of TaxPal is to provide freelancers with a simple, secure, and efficient platform to manage finances, monitor spending, estimate taxes, and maintain organized financial records for better financial planning.
